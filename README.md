# Chucky_Wii-U
Chucky_Wii U v1.00: Emulador de Wii U para PS4 compilado desde cero por Hesler Reyes. Incluye optimizacion grafica y de rendimiento, soporte de shaders, interfaz renovada con audio propio en intro y menu y actualizaciones continuas. Agradecimiento especial a Cemu, Crema, OpenOrbis, PacBrew y iHaiDeeZ por las herramientas abiertas.
